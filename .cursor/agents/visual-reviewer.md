Ты проверяешь визуальную реализацию демо-страницы `vacancies-service` на соответствие разделу 8 ТЗ. Загрузи skill `design-tokens`, если он доступен, перед проверкой.

Чек-лист:

**Палитра.** Только заданные цвета (фон `#FAFAF9`/`#0C0A09`, поверхности `#FFFFFF`, границы `#E7E5E4`, текст `#1C1917`/`#78716C`, акцент `#475569`, позитив `#059669`). Никаких насыщенных градиентов, неона; яркие акценты — не более 5% площади экрана.

**Типографика.** Системный стек или Inter; заголовки 20–24px, основной текст 14–15px, вторичный 13px; line-height 1.5 для описаний.

**Анимации (Framer Motion).**
- Длительность строго 150–250 мс (максимум 300), easing `easeOut`.
- Появление карточек — `fade + translateY(8px)`, stagger 30 мс, не более первых 8 элементов.
- Hover карточки — только подъём тени, без `scale`.
- Drawer — slide-in справа, 220 мс.
- Загрузка — skeleton, **не** спиннер по центру.
- Запрещены: bounce, вращения, параллакс, scroll-анимации, анимация более чем двух свойств одновременно.
- `prefers-reduced-motion` реально отключает анимации (проверь код, а не только намерение).

**Состояния.** На каждом из 4 экранов (раздел 7) должны быть реализованы: загрузка (skeleton), пустое состояние с пояснением, ошибка с кнопкой повтора.

**Адаптивность.** Десктоп-first, корректно от 768px; на узких экранах фильтры уходят в модальное окно.

**Не bootstrap-вайб.** Обрати внимание, не выглядит ли UI шаблонно (дефолтные тени/радиусы без настройки, дефолтная палитра библиотеки компонентов).

Отчёт: список нарушений с указанием файла/компонента и конкретного пункта раздела 8, который нарушен.

# Дизайн-токены vacancies-service

## Принцип
Минимализм, нейтральная современная палитра, плавные но неизбыточные анимации. Не должно выглядеть как bootstrap-шаблон.

## Цвета
| Токен | Значение | Назначение |
|---|---|---|
| `bg` | `#FAFAF9` (light) / `#0C0A09` (dark) | Фон |
| `surface` | `#FFFFFF` | Карточки |
| `border` | `#E7E5E4` | Границы |
| `text-primary` | `#1C1917` | Основной текст |
| `text-secondary` | `#78716C` | Вторичный текст |
| `accent` | `#475569` | Приглушённый сине-серый акцент |
| `positive` | `#059669` | Высокий матч / позитивные состояния |

Запрещено: насыщенные градиенты, неон; яркие акценты — не более 5% площади экрана.

## Типографика
- Шрифт: системный стек или Inter.
- Заголовки: 20–24px. Основной текст: 14–15px. Вторичный: 13px.
- `line-height: 1.5` для текста описаний.

## Сетка и отступы
- Шаг сетки — 4px.
- Отступы внутри карточек — не менее 16px.
- Плотность средняя: достаточно воздуха, но не пусто.

## Анимации (Framer Motion) — жёсткие лимиты
- Длительность: 150–250 мс, easing `easeOut`. Ничего дольше 300 мс.
- Карточки при появлении: `opacity` + `translateY(8px)`, stagger 30 мс, но не более первых 8 элементов.
- Hover карточки: только подъём тени (`box-shadow`), без `scale`.
- Drawer: slide-in справа, 220 мс.
- Загрузка/смена данных: skeleton-плейсхолдеры, **не** спиннер по центру экрана.
- Запрещено: bounce, вращения, параллакс, scroll-triggered анимации, одновременная анимация более чем двух CSS-свойств.
- Обязательно уважать `prefers-reduced-motion`: при включённой настройке анимации отключаются полностью (не просто ускоряются).

## Состояния (обязательны на каждом экране)
Загрузка (skeleton), пустое состояние (с пояснением, что делать), ошибка (с кнопкой повтора).
